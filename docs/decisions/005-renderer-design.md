# ADR-005: تصميم العارض

**الحالة:** مقبول
**التاريخ:** 2026-10-02
**صاحب القرار:** عمرو محمد (المشرف)
**يُكمل:** ADR-004 (استراتيجية عرض HTML)

## السياق

في ADR-004، قررنا عرض عناصر HTML المختارة كأدوات واجهة، بدل النص الخام. وقد أنجزنا الجزء الأول: محلل HTML في مجلد المحلل، الذي يحوّل النص إلى شجرة عقد.

الآن نحتاج قرارًا معماريًا للجزء الثاني: كيف نحوّل الشجرة إلى عناصر جي تي كي؟

## الخيارات المدروسة

### الخيار الأول: دالة واحدة كبيرة

دالة واحدة تمشي على الشجرة وتُنتج عنصراً واحداً مركّباً.

**رُفض.** صعب الصيانة، ولا يقبل التوسّع.

### الخيار الثاني: صنف العارض

صنف العارض يستقبل الشجرة، ويُنتج عنصر جي تي كي.

**مقبول.** يفصل المنطق، ويقبل التوسّع.

### الخيار الثالث: زائر

نمط الزائر، حيث يزور كائن ما كل عقدة، ويُنفّذ عملية.

**رُفض.** معقّد أكثر من اللازم للمرحلة الحالية.

## القرار

نعتمد **الخيار الثاني**: صنف العارض في ملفي الرأس والتنفيذ.

## واجهة الصنف

    namespace honeybee::renderer {

    class Renderer {
    public:
        // يحوّل شجرة العقد إلى عنصر جي تي كي واحد.
        // العنصر المُعاد هو حاوية عمودية تحتوي على كل العناصر.
        static Gtk::Widget* render(const html::NodePtr& root);
    };

    }

## استراتيجية التحويل

### الوسوم المدعومة

| الوسم | عنصر جي تي كي |
|------|---------------|
| العنوان الأول حتى السادس | نص بخط كبير، بحجم يتناقص |
| الفقرة | نص عادي مع هامش |
| الرابط | زر رابط مع النص |
| القائمة النقطية | حاوية عمودية بأبناء نقطيين |
| القائمة المرقمة | حاوية عمودية بأبناء مرقمين |
| العنصر | نص مع نقطة أو رقم |
| الفاصل | نص فارغ بارتفاع صغير |
| التمييز والتوكيد | نص بخط عريض |
| التمييز البسيط | نص بخط مائل |
| الحاوية | حاوية عمودية شفافة |
| النطاق | نص عادي |
| النص المجرد | نص عادي |

### الوسوم غير المدعومة

تُعامَل كحاويات شفافة: نعرض أبناءها فقط، بلا تنسيق خاص.

## البنية الإخراجية

- الجذر يُنتج حاوية عمودية.
- كل عنصر ابن يُضاف إلى الحاوية.
- النصوص تُلَف في عناصر نصية.
- إدارة الذاكرة: دالة الإدارة في جي تي كي تتولى تحرير العناصر عند تحرير الأب.

## النطاق

**داخل النطاق:**
- الوسوم المذكورة في الجدول أعلاه.
- محاذاة النص إلى اليسار، للعربية.
- هوامش بسيطة حول الفقرات.

**خارج النطاق:**
- CSS بأي شكل.
- الجداول.
- الصور.
- النماذج.
- التفاعل، باستثناء نقر الروابط.

## النتائج المترتبة

- العارض يعتمد على جي تي كي، فلا يمكن اختباره بوحدات اختبار تقليدية.
- الاختبار سيكون يدوياً على صفحات حقيقية.
- العارض يحل مكان عنصر النص المؤقت في النافذة.
- المستقبل: عند إضافة CSS، سيُوسّع العارض.
